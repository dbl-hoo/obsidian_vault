Use the generic civilian/personal record request code, **109-578** ("Applicant" — individual requesting own record), when checking in at 1st Choice Fingerprinting. Tell them it's for an out-of-state licensing application.

**Ohio (BCI):** Not in-state for WebCheck fingerprinting — need to request a fingerprint card, get inked prints locally, mail card + payment + exemption form to BCI in London, OH. Turnaround ~2-4 weeks via mail. Info: https://www.ohioattorneygeneral.gov/backgroundcheck

**Washington (WSP):** WATCH online system (https://watch.wsp.wa.gov/public/watch) — name-based search, $11, instant results, WA convictions only. Mail option also available (WSP, Identification and Background Check Section, PO Box 42633, Olympia, WA 98504-2633) if a more formal/certified copy is needed.

**Timing:** PA requires CHRC dated within 90 days of PA receiving the application — don't order too early. Ohio mail-in is the long pole, start that first. Open question: does PA require fingerprint-based state checks specifically, which would rule out WATCH's name-based search.
